# 长期避坑知识库

## 用途

本目录保存经过 Git、项目文件、当前对话或实际命令验证的工程经验，避免后续 Codex/AI 重复踩坑。`AGENTS.md` 只维护强制规则和入口，具体坑统一记录在这里。

## 读取规则

任何开发、修复、测试、部署或排障任务开始前：

1. 先读取项目根目录 `AGENTS.md`。
2. 再读取本文件。
3. 根据任务涉及的模块读取下方索引中的相关文件。
4. 不能把未阅读知识库作为重复尝试已知错误方案的理由。

## 写入规则

1. 初始历史回填只执行一次，已于 2026-07-12 完成；以后只做增量追加或基于新证据修正。
2. 只记录有 Git、项目文件、对话上下文或实际验证结果支持的内容。
3. 新坑必须在当前任务收尾前写入；任务中断时尽量记录已确认发现，并标明未完成部分。
4. 优先写入对应模块文件；无法合理分类时写入 `general.md`，需要时再建立该文件。
5. 更新或新增分类文件后，同步维护本文件的索引和回填统计。
6. 禁止写入密钥、Token、账号密码、隐私数据、生产配置全文或完整敏感日志。

## 条目格式

每条坑使用 Markdown 二级标题，并完整包含：

- **现象**
- **根因**
- **正确做法**
- **验证方式**
- **禁止事项**
- **相关文件或命令**
- **适用范围**

证据不足时必须标注“信息不全，待人工补充”或“以下为基于现有证据的推测”，不得补写未经验证的细节。
