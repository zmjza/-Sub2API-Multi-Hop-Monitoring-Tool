# 术语表

上级：[[00-项目说明书]]
下级：全部模块文档
依赖：无

| 术语            | 定义                                                                                                                                                        |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 站点            | 一个可登录的 sub2api 二开服务地址及其本地配置                                                                                                               |
| 正式站点        | 已通过登录和核心能力检测、会参与刷新与汇总的站点                                                                                                            |
| 草稿/失败项     | 尚未通过验证、只保留在录入界面的临时数据                                                                                                                    |
| 能力矩阵        | 记录某站是否支持登录、刷新、余额、Key、倍率、统计、记录和渠道监控                                                                                           |
| 默认 Key        | 悬浮窗和站点详情当前使用的 API Key 摘要，不包含完整 Key                                                                                                     |
| 自动模式        | 按本机时区选择今天请求次数最多的有效 Key                                                                                                                    |
| 手动模式        | 用户持久化指定 Key；失效时临时回退自动模式                                                                                                                  |
| 实际倍率        | 用户专属倍率优先、否则分组默认倍率的最终展示值                                                                                                              |
| 实际消费        | `total_actual_cost`，倍率等规则作用后的真实扣费                                                                                                             |
| 标准费用        | `total_cost`，未按最终实际扣费口径展示的参考费用                                                                                                            |
| 有效缓存        | 当前时间未超过 `expiresAt` 的最后成功数据，可计入汇总                                                                                                       |
| 过期缓存        | 已超过 `expiresAt` 的数据，仅作参考，不计入汇总                                                                                                             |
| 部分成功        | 站点核心数据有可用结果，但一个或多个能力请求失败                                                                                                            |
| 当前站          | 悬浮窗或主面板正在查看的站点，拥有调度最高优先级                                                                                                            |
| 后台站          | 当前未查看但仍在低频刷新的站点                                                                                                                              |
| Stitch 接收检查 | 以 HTML 为第一事实来源，核对实例尺寸、样式、状态、文件白名单和预览入口的视觉门禁；不是 Product Design Design QA                                             |
| 视觉参考尺寸    | Stitch 以 `1440 x 1024` 作为布局核对参考；Renderer 实际响应式铺满 BrowserWindow，不使用固定画布等比缩放                                                     |
| 主窗口占屏比    | 主 `BrowserWindow` 初始宽高相对主屏工作区的比例，当前为 `60% x 90%`                                                                                         |
| Token 紧凑格式  | UI 中小于 1000 显示原值，达到 1000 使用 K，达到 1,000,000 使用 M，最多两位小数并去除末尾无意义的 0；CSV 保留原值                                            |
| 思考等级        | 使用记录的 `reasoning_effort`，兼容 `low`、`medium`、`high`、`xhigh`、`max`；缺失显示 `—`                                                                   |
| 有效倍率        | 用户专属分组倍率、Key 内嵌分组倍率和可用分组默认倍率按证据优先级解析后的显示值；缺失时明确不可用                                                            |
| 四角停靠        | 悬浮窗在当前显示器工作区的左上、右上、左下或右下定位，默认右上并持久化，显示器变化时回退可见位置                                                            |
| 非置顶桌面常驻  | 悬浮窗保持已显示且不因切换应用自动隐藏，但不使用 `alwaysOnTop`，浏览器等前台应用可覆盖；macOS 可跨 Space 可见但不覆盖全屏应用，不等同于贴在壁纸或桌面图标层 |
| 数据过期阈值    | 用户可配置的最后成功数据过期时间；超过后显示 stale，不用旧值冒充实时成功                                                                                    |
| UI 壳           | 落在真实前端文件中的结构、样式和状态外观，不包含真实业务接线                                                                                                |
| 内部测试通过    | 代码主链路通过内部验证，尚未完成真机验收                                                                                                                    |
| 真机测试        | Codex 在当前 macOS 上对真实桌面应用进行实际操作验证                                                                                                         |
| Windows CI 验证 | Windows Runner 上的构建、启动和自动化检查，不等同真机验收                                                                                                   |
| Codex Radar     | 正式主导航中的公开模型摘要页面，只读取明确的 `codexradar.com` HTTPS 数据，不属于站点监控业务链路                                                            |
| 功能级合并      | 从外发版按能力、调用方、测试和安全边界移植到主线，不等于整文件覆盖                                                                                          |
| 渠道关系候选    | `/channels/available` 提供的平台、分组和模型关系；只有唯一匹配才可作为首选，不确定时保持未确定                                                              |
| 悬浮窗透明度    | 原生窗口 opacity 的整数百分比设置，范围 `35..100`，默认 `84`；不等同 Renderer 全局透明                                                                      |
