## 已确认视觉基线

- 只提供固定浅色模式，不设计深色、跟随系统或主题切换；支持减少透明效果和高对比度。
- 克制液态玻璃仅用于窗口外壳、侧边导航、顶部工具栏、悬浮窗和浮层；密集数据、表单、表格、时间线和危险区使用高不透明表面。
- `1440 x 1024` 是 Stitch 视觉参考尺寸；Renderer 响应式铺满 BrowserWindow，不使用固定画布缩放。Electron 主窗口默认占主屏工作区 `60% x 90%`，自动居中、可缩放；左侧导航固定在内容区。悬浮窗逻辑尺寸为 `380 x 260`。
- 禁止营销首页、卡片墙、巨大标题、渐变球、紫蓝单色主题、嵌套卡片和低信息密度。

## 真实预览入口

- 主面板：`/?surface=main`。开发模式可启用受控 PreviewControls；生产打包态由正式导航切换四个主面板业务界面，不显示预览控制器。
- 悬浮窗：`/?surface=floating`，由独立 Electron `BrowserWindow` 加载；固定 `380 x 260`，生产态读取当前站 ViewModel。
- 启动：`npm run dev`；仅 Renderer 浏览器预览可用 `npm run dev` 后访问 `http://127.0.0.1:5173/?surface=main`。
- Radar 的两个默认网页不是 Renderer surface 路由：生产窗口由主进程在当前 `BrowserWindow` 的内容区挂载受限 `WebContentsView`；Renderer 通过 preload 操作持久化列表并按 ID 打开，接收生命周期状态。
