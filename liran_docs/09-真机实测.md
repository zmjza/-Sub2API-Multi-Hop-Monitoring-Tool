## 2026-07-20 1.3.4 倍率卡片内联渠道状态与视觉验收

- 环境：macOS 26.5，Apple Silicon；开发 Electron 与未签名 `1.3.4` ARM64 打包应用，隔离 userData。
- 自动化：Prettier、ESLint、TypeScript、Vitest 28 文件/154 项；开发 Electron E2E 6/6；`1.3.4` 打包应用 E2E 6/6。
- 页面样式：默认窗口检查 OpenAI/Claude/Gemini/Grok 固定一行及浅绿/浅橙/浅蓝/黑灰主题；窄窗口检查不换行、横向滚动、加载动画、错误重试和长文本截断。
- 交互：倍率卡片无需点击即可显示匹配渠道状态、7 天可用率和时间线；无渠道状态显示标签；点击站点级入口才加载完整渠道弹窗，弹窗 UI 与渠道状态壳一致。
- 页面证据：`real-test-evidence/macos-1.3.4/01-inline-channel-overview.png`、`02-inline-channel-retry.png`、`03-channel-status-popover.png`、`04-narrow-window.png`、`06-horizontal-scroll-grok.png`。
- 发布结构：DMG `hdiutil verify` 通过；macOS Mach-O ARM64；Windows NSIS/PE32、主程序 PE32+ x86-64；两端 asar `1.3.4` 且入口完整。Windows 不作真机结论。

结论：`1.3.4` macOS 真机页面、交互和打包应用 E2E 通过；Windows 仅交叉构建与结构验证。
