### 状态矩阵与高风险控件

状态矩阵：unsupported 显示局部能力缺失；degraded/failed/unknown 只作用渠道卡；stale/error 保留最近卡片；loading/empty 使用稳定网格占位。高风险控件为长渠道名、多模型标签、状态 pill、延迟数值、60 格时间线和周期切换。
