### 状态矩阵与高风险控件

状态矩阵：draft/success 保留表单；loading/refreshing 显示验证步骤；partial 显示逐行成功/失败；error 保留用户输入；disabled 表达权限或任务中；empty 用于无站点。高风险控件为密码显隐按钮、52px 输入框、验证进度、批量任务行、通知开关和危险删除操作。
