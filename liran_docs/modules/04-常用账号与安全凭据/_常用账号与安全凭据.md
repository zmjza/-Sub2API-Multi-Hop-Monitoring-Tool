# 站点安全凭据（原常用账号模块路径）

## 2026-08-04 1.7.7 交互输入安全边界

- 账号和密码只在主进程创建的临时官方登录窗口中按用户当前站点输入使用；异步表单填充不覆盖用户已有输入。
- 认证成功前不写入站点、凭据或缓存；取消/超时/失败清理临时 session，Token 和验证码结果不经过 Renderer、日志或文档。

## 2026-08-04 1.7.3 凭据会话收口

- access token 是交互会话最低保存条件，refresh token 可选；交互站点续期失败进入 `auth-required`，不静默密码重登。
- 重新验证写入失败保留旧凭据；同地址不同账号继续按 `siteId` 隔离，删除时清理对应站点的全部缓存引用。

## 2026-08-04 1.7.2 同站多账号与保存回滚

- 同地址不同用户名继续使用独立 `siteId` 和安全凭据；同地址同用户名按邮箱大小写/首尾空格规则拦截。
- 保存任一阶段失败时移除该 `siteId` 的凭据、引用和缓存，不用不完整数据猜测账号身份。

## 2026-08-03 1.7.0 交互会话轮换与旧凭据保护

- GeeTest/Turnstile Token 和账号密码继续只进入 `CredentialVault`；交互窗口临时 session 结束后清理，Renderer/SQLite/日志不接触 Token。
- 主动重新验证必须先用新 Token 完成 profile、Key、分组、倍率和今日统计验证，再原子更新原 `siteId`；任一失败都保留旧 access/refresh token、provider、快照和 Key 缓存。
- 同地址不同用户名的凭据完全按 `siteId` 隔离；重复检查只读取安全凭据中的账号身份，不写入明文账号表。

> 2026-07-14 真机回写：常用账号功能已取消；站点独立凭据已通过 safeStorage 加密、原子轮换、普通 SQLite 无明文和 macOS 打包应用跨重启恢复验证。隔离 GUI 删站后安全后端条目为 0，重启仍为空。

## 职责

管理每个站点自身的账号密码引用、安全更新和删除。常用账号功能已取消，本文件因禁止删除而保留原路径，不再定义模板业务。覆盖 RQ-14、RQ-15。

## 生命周期规则

- 站点保存独立 credentialVersion 和安全引用，普通 SQLite 字段不存明文密码。
- 凭据更新采用：创建候选密文 -> 测试当前站点 -> 成功后原子切换 -> 失败时保留旧版本。
- 删除站点时删除该站凭据和 Token，不影响其他站点。

## 状态

idle、encrypting、testing、updated、failed-safe。

## 安全边界

- 明文仅存在于最短必要内存；Renderer 不可读取已保存密码。
- 密文、secretRef、Token 不进入日志和普通导出。

## 验收

- 站点凭据候选测试、失败保留旧凭据、删站清理和重启后解密均有测试；macOS Keychain 行为真机验证。
