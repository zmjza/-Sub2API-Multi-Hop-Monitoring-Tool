## 测试层次

- Vitest：纯逻辑、仓储、适配器、调度和安全单元测试。
- mock sub2api：认证、能力、错误和多站集成测试。
- Playwright Electron：录入、切站、筛选、加载、失败恢复、无框窗口、主窗/悬浮窗切换、四角停靠、设置持久化和主要页面流程。
- macOS 真机：悬浮窗、托盘、通知、Keychain、开机启动、多显示器和主要页面。
- Windows CI：构建、启动、测试；不得标 Windows 真机通过。
- 视觉验证：固定浅色、减少透明、高对比度和不同窗口尺寸，并检查不存在其他主题入口；`1440 x 1024` 仅作视觉参考，Renderer 必须铺满 BrowserWindow，左侧菜单固定。macOS 检查实际窗口与页面，Windows 只记录自动化/交叉构建证据。
- Stitch 产物验证范围：5 个业务 Screen 的 HTML/截图来源登记、控件规格盘点、实例级尺寸保真、无敏感静态数据、Design System 与项目固定浅色需求冲突检查。
- 本 Stitch 路线的视觉证据采用 HTML 事实、实例级规格、构建、入口、自动化截图和 macOS 打包应用人工检查，不执行另行的设计评审流程。
