## 职责

实现主面板与悬浮窗的稳定窗口行为、站点切换、动态标题、位置恢复和托盘操作。覆盖 RQ-03、RQ-11、RQ-12。

## 叶子能力

窗口行为按定位、站点交互、动态标题和托盘四个叶子职责拆分。

### 悬浮窗定位

- 默认主显示器右上角，可选择左上、右上、左下、右下四角并持久化。
- 按当前主显示器 workArea 和 12px 边距重新计算位置；显示器或工作区变化时回退主显示器可见区域。
- 固定响应式约束，查询动画、长站点名和错误状态不得改变外框尺寸。
- Stitch HTML 已确认悬浮窗逻辑规格为 `380 x 260`，只实现固定浅色外观；`1440 x 1024` 仅为主界面视觉参考，Renderer 必须响应式铺满 BrowserWindow。主窗口初始占工作区宽度 60%、高度 90%，居中且可从边缘和四角缩放。
- 悬浮窗可使用克制玻璃材质，但数值和状态必须位于可读表面；减少透明效果时降级为高不透明实色面板，高对比度时强化边框和焦点。
- 悬浮窗保持已显示但 `alwaysOnTop=false`；所有非用户主动打开路径使用 `showInactive()`，不得调用 `focus()` 激活应用。切换浏览器、其他应用或台前调度组时不得自动隐藏，前台应用必须能覆盖它。macOS 跨 Space 可见但 `visibleOnFullScreen=false`；Windows 保持普通窗口层。

### 站点切换与点击

- 左右按钮循环切站；无站点或单站时相应禁用。
- 切站立即展示缓存并提交高优先级刷新。
- 点击非控制区打开当前站详情；图标按钮使用工具提示。

### 动态标题

- 余额 >=2、<2、未知三态使用已确认文案。
- 余额来源必须对应当前选中站点，不能使用跨站总余额。

### 托盘

- 打开主面板、显示/隐藏悬浮窗、开机启动开关、退出。
- 菜单状态与真实窗口/设置同步。
- 主窗口最小化在悬浮窗启用时显示悬浮窗，禁用时仅隐藏到托盘；关闭按钮直接退出。

## 验收

- 四角停靠、持久化、长文本、切站、失焦保持、非激活显示、前台应用覆盖、台前调度跨 Space、固定浅色和关闭退出需有自动化与 macOS 打包应用证据；减少透明、高对比度和物理多显示器在具备对应系统/硬件条件时补充，不冒充已通过。

## 2026-07-18 外发版合并增量（内部测试通过；真机待实测）

本轮 macOS ARM64 内部目录包已完成透明度、固定尺寸、非激活显示和跨重启验收；页面截图见 `real-test-evidence/macos-1.1.0/playwright/05-floating.png`。Windows 仅保留交叉构建证据。

- macOS 与 Windows 均保持 `alwaysOnTop=false`；macOS 继续 `visibleOnAllWorkspaces=true` 且不覆盖全屏，Windows 保持普通窗口层。

- 恢复坐标按可见工作区校正，支持负坐标显示器；显示器消失或完全越界时回退主显示器右上角。

## 2026-07-19 1.3.1 最新使用站点自动跟随（macOS 真机通过）

- 仅悬浮窗 Renderer 复用现有 `usage` IPC，按每站最近一条 30 日记录比较 `createdAt`；不新增后端接口或持久化字段。
- 可见悬浮窗每 2 秒扫描一次，上一轮未完成时跳过，不产生重叠请求；单站失败局部忽略，全部无有效时间时保持当前显示。
- 全局最新记录改变后只更新悬浮窗本地 `currentSiteId`，不会调用 `sites.select`，不会改写数据库或主窗口当前站点。
- 隐藏时暂停扫描，重新可见立即补扫；相同时间按稳定站点 ID 决定，避免标题随机跳动。
- 打包应用本地两站时间先后切换验证标题自动更新为最新站点，证据为 `real-test-evidence/macos-1.3.1/05-floating.png`。
