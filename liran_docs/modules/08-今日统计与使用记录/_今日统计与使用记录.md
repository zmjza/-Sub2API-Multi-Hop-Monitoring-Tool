## 职责

提供本机时区今日统计和按需使用记录。覆盖 RQ-06、RQ-07。

## 今日汇总

- 传递 IANA 时区和 `period=today`；必要时按 Key 传 `api_key_id`。
- 映射请求、输入、输出、缓存读写、总 Token、实际/标准费用和平均耗时。
- 本地零点使今日查询失效并触发默认 Key 重新计算。

## 使用记录

- 当前站点使用真实下拉框；切站时清空旧站点记录、渠道、Key 和筛选枚举，避免旧数据冒充新结果。
- 模型来自 `/usage/dashboard/models`，分组来自 `/groups/available`，Key 来自 `/keys`；支持时间预设、自定义日期、请求类型、计费类型、计费模式、分页和排序。
- 每页固定请求并渲染最多 20 条，页面不使用纵向无限滚动；表格仅在列宽不足时横向滚动。
- 时间按用户本地时区显示为 `MM月 dd日 HH时 mm分 ss秒`；展示 `reasoning_effort` 思考等级，缺失显示 `—`。
- 总 Token 和行内 Token 使用 K/M 缩写，CSV 保留原始数值；不存在地区字段或地区操作。
- 筛选变化取消旧请求，防止迟到响应覆盖新结果。
- CSV 在本地从已获取/明确导出范围的数据生成，列顺序和脱敏规则可控。
- 完整记录不长期落库。
