## 微观任务

- **UF-01 统一查询契约**：目标是让 list/stats/CSV 共用一个规范化筛选对象；输入为现有 UsageQuery 与上游参数；文件为 contracts 及测试；边界为日期完整性、字符串枚举和时区；RED 覆盖 list/stats 参数漂移和非法日期；步骤为 schema/helper 测试后实现；验证 contracts 测试；完成条件是三条路径序列化一致；依赖 AK-03 可并行；禁止 Renderer 自拼上游 URL。
- **UF-02 stats 适配器**：目标是读取 `/usage/stats` 并只归一化四个顶部指标及必要 token 明细；输入为 UF-01；文件为 adapter/schemas/tests；边界为缺失字段 undefined、0 合法；RED 覆盖实际消费缺失、平均耗时 0、上游额外字段；步骤为 fixture 后实现；验证 adapter 测试；完成条件是严格 ViewModel；依赖 UF-01；禁止用列表求和。
- **UF-03 服务与 IPC**：目标是提供同条件 usage list 与 stats 调用并独立失败；输入为 UF-01/02；文件为 site-service、main IPC、preload、测试；边界为站点认证和输出 parse；RED 覆盖 list 成功 stats 失败及反向组合；步骤为服务测试、handler、bridge；验证集成测试；完成条件是两个结果可独立更新；依赖 UF-02；禁止把站点默认快照作为筛选统计。
- **UF-04 300ms 查询协调器**：目标是筛选变化防抖、页码复位、取消旧请求并拒绝迟到响应；输入为规范化查询；文件为新/现有 usage coordinator、App、测试；边界为手动刷新绕过防抖、日期完整后才发；RED 覆盖快速六次选择、切站、卸载；步骤为 fake timer 测试后实现；验证 coordinator 测试；完成条件是仅最后查询提交；依赖 UF-01/03；禁止每个控件各建请求逻辑。
- **UF-05 页面统计接线**：目标是顶部卡片显示筛选 stats 并保留旧内容的局部 loading；输入为 UF-03/04；文件为 UsagePage、types、App、测试；边界为统计 error 与列表 error 分离；RED 覆盖切换条件后旧数值不冒充当前成功；步骤为组件测试后接线；验证 UsagePage 测试；完成条件是四指标与当前 query revision 一致；依赖 UF-04；禁止读取 selectedSite 今日指标。
- **UF-06 筛选交互与日期**：目标是所有六类下拉和日期变化自动生效，重置/分页/排序正确；输入为现有控件；文件为 UsagePage/usage.css/tests；边界为视觉不重做、筛选变化回第一页；RED 覆盖相同值、无效自定义日期、重置；步骤为交互测试后最小修改；验证组件测试；完成条件是无需点刷新；依赖 UF-04/05；禁止删除强制刷新。
- **UF-07 CSV 同口径**：目标是导出使用当前完整筛选且保持公式注入防护；输入为 UF-01；文件为 site-service/domain csv/UsagePage/tests；边界为原始数值、脱敏 Key、明确最大页策略；RED 覆盖筛选遗漏与公式前缀；步骤为失败测试后复用查询；验证 csv 与组件测试；完成条件是导出参数与当前 UI 相同；依赖 UF-01/03；禁止导出完整 Key。
- **UF-08 跨模块回归**：目标是证明筛选、统计、分页、切站、Key 选项和旧字段不回归；输入为 UF 最终 diff；文件为 UsagePage、App、adapter、E2E 测试和文档；边界为只更新真实证据；RED 补充 auth/unsupported/partial；步骤为完整测试、截图、diff 审计；验证 lint/typecheck/test/build 后串行 E2E；完成条件是顶部与真实接口同口径；依赖 UF-01..07；禁止把未跑真机写成通过。
