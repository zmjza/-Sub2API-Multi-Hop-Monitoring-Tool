# 数据字典

## 1.9.0 增量数据口径

- `tokensPerSecond: number | null`：仅由 `outputTokens * 1000 / durationMs` 派生，不持久化；输入缺失、非有限或 `durationMs <= 0` 时为 `null`。
- `speedTier: 'slow' | 'normal' | 'fast' | 'unavailable'`：分别对应 `<20`、`20..<50`、`>=50` 和无有效速度。
- `siteOrder: string[]`：本地持久化的站点 ID 顺序；读取时与真实站点集合对账，保留有效 ID、去重、追加新 ID、清理已删除 ID。
- 站点安全元数据增加可选 `iconUrl`；仅允许主进程从已验证站点同源图片取得，失败不持久化不可信值，Renderer 回退 `Globe`。
- 渠道稳定窗口固定为最近 `60_000ms`；明确失败值只有 `failed/error/down/unavailable`，`unknown/degraded/empty` 保持既有语义。
- 批量验证任务仍是当前 Renderer 会话状态，不新增跨重启历史表；站点名称、图标和顺序属于已保存站点数据。

## 2026-07-18 1.2.0 优化字段

- `firstTokenMs`：usage `first_token_ms`，仅允许有限数值；负数在展示层视为无效并显示 `—`。
- `durationMs`：usage `duration_ms`，与首字使用相同的可读时长格式。
- `quota` / `quotaUsed`：`/keys` 安全摘要中的 Key 总额度/已用额度；仅手动 Key 且 quota 有效正数时参与总额减已用计算。
- `SiteSummary.note`：本地站点备注，最大 500 字，存储键为 `site:<siteId>:note`，不进入凭据和网络请求。

## 展示与持久化边界

- K/M 仅是 Renderer 展示格式，Token 原始整数继续用于计算、IPC 和 CSV，不把缩写字符串写回业务模型。
- `reasoningEffort` 保留上游可识别枚举；未知非空值以安全文本展示，不将其提升为已支持枚举。
- `effectiveRate` 必须同时记录 `source`，用于区分用户专属、Key 内嵌分组和可用分组默认倍率；没有可信来源时为 `null`。
- `floatingCorner` 默认 `right-top`。主窗口最小化与悬浮窗开关的组合属于窗口状态，不伪装成业务数据。
- 通知权限支持状态由操作系统实时查询，不把授权结果伪造成可写的应用偏好。

## 凭据生命周期

1. 表单中的明文密码只存在于最短必要内存。
2. 测试成功后使用 `safeStorage.encryptString` 加密，再保存密文或平台安全引用。
3. 站点凭据更新采用“新凭据先测试、成功后原子切换、最后清理旧引用”；失败时保留该站原凭据。
4. 常用账号模板已取消，不创建模板实体、模板关联或批量凭据同步生命周期。
5. 第一版已实现 `sites`、`credential_refs`、`auth_sessions`、`snapshots`、`settings` 和 `notification_states` 表；普通 SQLite 不保存密码、Token 或完整 Key。
6. 删除站点时清理站点凭据、Token、缓存和通知状态。

## 数据保留

- 普通缓存默认 30 天。
- 最新快照长期保留至站点删除，但超过 TTL 后标为过期且不计汇总。
- 使用记录列表仅按需缓存，不作为完整历史数据库。
- 日志保留策略在实现阶段确定，但必须经过脱敏且可由用户清理。

## 第一次 `/goal` 落地状态（2026-07-13）

- `settings` 已保存当前站点、自动/手动 Key 偏好、通知设置和窗口 bounds；开机启动由操作系统登录项保存。
- `notification_states` 已保存低余额 fingerprint 与最后发送时间，支持跨进程重启冷却。
- `sites.capability_json` 已保存核心能力、使用记录和渠道监控 supported/unsupported/error/unknown 状态。
- `snapshots` 已包含余额、今日请求数、输入/输出/缓存 Token、实际费用、标准费用、平均耗时和更新时间；30 天清理已接入启动与每日任务。
- 使用记录仍只按需读取，不进入完整长期数据库；CSV 由主进程即时生成并执行公式注入保护。
- 密码、access token、refresh token 只进入 `safeStorage` 加密载荷及最短必要内存；普通 SQLite、Renderer ViewModel 和 CSV 不包含这些字段。

## 2026-07-19 1.2.1 字段增量

- `site:<siteId>:keyCache`：只保存 `id/name/maskedLabel/status/groupId/groupName/quota/quotaUsed/rate` 白名单摘要，不保存完整 Key；管理页的完整值不进入该缓存。
- `site:<siteId>:keyPreference`：每站点保存 `{ mode: 'auto' }` 或 `{ mode: 'manual', keyId }`；无缓存升级期保留，确认失效后回退自动。
- `floatingSettings`：兼容四角 `{ position, opacity }`；自由拖动保存 `{ position: 'custom', x, y, opacity }`，经共享 schema 校验。
- Usage 可见 Token 行模型包含 input/output/cacheRead 三项；CSV 安全模型继续保存原始白名单数值。

## 2026-07-19 1.3.0 倍率比较字段

- `AvailableRateGroup`：仅允许 `id/name/description?/platform/status?/rate`；`rate` 来自有限非负 `rate_multiplier/ratio/rate/default_ratio`，上游其他字段全部丢弃。
- `site:<siteId>:rateCache`：保存 `{ groups, fetchedAt }` 安全白名单缓存；刷新失败时保留上次数据并标记错误，不保存认证信息或原始响应。
- `site:<siteId>:rechargeRatio`：保存有限正数 `X`，展示为 `1:X`；预设为 1/5/8/10，自定义值同样必须大于 0。
- `effectiveRate`：只在比例已设置时按 `rate / X` 计算；未设置为 `undefined`，站点不参与跨站比较。比较保留零倍率和浮点容差内平局，展示最多六位小数。

## 2026-07-19 1.3.1 运行时评分与悬浮窗字段

- `priceScore`：运行时 0..10 数值，按同平台最低折算倍率归一化，不持久化。
- `stabilityScore`：运行时 0/3/5/10 数值；无渠道状态同样为 5，但通过独立文字标签区分，不持久化。
- `totalScore`：`priceScore * 0.6 + stabilityScore * 0.4`，排序使用未四舍五入值，展示保留一位小数。
- `RateChannelSnapshot`：仅保留渠道 `id/name/groupName/platform/status/timeline` 的安全摘要，用于当前 Overview 会话重新评分。
- `ChannelStatusCache`：Renderer 页面会话内按站点保存渠道列表信封和按渠道 ID 的详情信封，页面卸载即释放，不写入 SQLite。
- `latest usage site`：只在悬浮窗内保存最近有效 `siteId/usedAt` 比较结果，不保存使用记录正文，不改写持久化当前站点。
