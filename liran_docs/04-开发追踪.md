## 任务字段约定

每条任务均包含：目标/步骤、依赖、计划文件范围、TDD RED、正常路径、失败/边界、安全要求、验证/完成标准、文档回写和状态。除表格另有说明，安全通用要求为“不记录密码、Token、完整 Key；不扩大 IPC/文件/网络权限”，完成标准为“RED 已确认、最小实现通过目标测试、相关回归通过、diff 仅限计划范围”。

`P01 工程安全基线 → P02 数据存储 → P03 凭据认证 → P04 API 适配 → P05 调度聚合 → P06 桌面窗口 → P07 主面板业务基础 → P08 UI 壳准备 → P09 Stitch 承接 → P10 真实业务接线 → P11 通知设置 → P12 自动化与安全 → P13 macOS 验收准备 → P14 Windows CI/构建 → P15 Gitee 分发收口`
